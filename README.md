# The Anger of Achilles

Iliad Book One — Samuel Butler's translation retold as a Paul Graham-style essay, in one self-contained HTML page.

## Use

Open `book_1.html` in any browser. No build, no server, no dependencies.

## What's on the page

- **Essay** — Book One retold: the plague, the quarrel, Thetis calling in her favor with Zeus.
- **Decoder table** — Butler's Roman names (Jove, Juno, Ulysses…) mapped to the Greek ones used here.
- **Glossary** — the sixteen characters, one card each.
- **Relationship map** — SVG graph of who does what to whom.

## Interactions

- Hover or focus a dotted-underlined name in the essay for a character tooltip.
- Click a name (or a glossary card, or a map box) to highlight that character's connections on the map; everything else dims.
- Esc, the map background, or the "clear" chip resets. Keyboard and touch supported; respects `prefers-reduced-motion`.

## Files

- `book_1.html` — the whole app
- `book_1.md` — Butler's Book One, the source text
